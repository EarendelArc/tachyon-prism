# Tachyon Prism 安全模型

本文说明桌面后端当前强制执行的安全边界。提交安全报告时，请勿附带订阅地址、节点 URI、Xray JSON、Tachyon PSK，或可能含凭据的运行日志。

## 运行时所有权

系统代理只归受管 Xray 进程所有。Xray 未运行时，Prism 拒绝启用系统代理。Tachyon Core 停止或失败不会修改 Xray 持有的代理事务。Prism 会在停止 Xray 之前、状态轮询发现 Xray 已停止或失败时，以及应用退出或崩溃恢复时，还原先前的系统代理快照。

Tachyon Core 永远不持有操作系统代理；它只传输已选择的游戏 UDP 流量。

## 订阅网络策略

订阅下载由 Rust 后端执行，只接受不含内嵌凭据的 HTTP 和 HTTPS 地址。每一次请求和重定向都会独立完成解析、DNS 解析和地址验证；验证通过的套接字地址随后被注入 HTTP 客户端解析器，从而把验证结果绑定到实际连接，同时保留 TLS 域名证书校验。

对于 IPv4 和 IPv6，Prism 默认拒绝回环、未指定、私网、共享、链路本地、多播、文档、基准测试、保留地址以及云元数据目标。重定向不得从 HTTPS 降级到 HTTP。无论使用何种策略，云元数据地址和主机名始终禁止访问。

此版本不开放本地或私网订阅。未来若实现，必须提供清晰标注、默认关闭且可持久化的显式开关；该开关不得放宽云元数据、链路本地、多播、文档或保留地址保护。

## 渲染器策略

Tauri 渲染器使用明确的内容安全策略。脚本只能从应用安装包加载；网络连接仅允许 Tauri IPC 与 Tachyon 遥测所需的回环运行时端点。任意远程 HTTP(S)、`unsafe-eval`、框架、对象和表单均被禁止。远程下载通过经过验证的 Rust 命令完成，而不是由渲染器直接 `fetch`。

## 敏感文件与诊断

运行时设置、Xray 配置、Tachyon 配置、代理恢复日志及原子写候选文件都使用统一安全写入器。Unix 文件权限为 `0600`；Windows 使用受保护 DACL，仅向当前用户、Local System 和 Administrators 授予完全访问权限。原子替换完成后会再次对正式文件应用该策略。

Xray 诊断信息在进入 UI 前会经过脱敏和长度限制。新增后端错误不得包含配置正文、PSK、订阅凭据、节点 URI 或授权请求头。

把渲染器存储中的凭据迁移到操作系统凭据库属于独立后续任务，本文不宣称该迁移已经完成。
